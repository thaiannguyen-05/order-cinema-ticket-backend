10 — Risks / improvement candidates (display only)

1. Double-book race. Ticket has no booking write API; POST /payment/order does check-then-create with no seat-hold/Redlock/transaction. Concurrent orders for same ticketId/seatId can race.
2. DI fragility. PaymentModule imports TicketModule but TicketService not exported.
3. resetPassword field. Writes password vs column hashPassword — confirm migration.
4. SePay callback guard. POST /payment/sepay/callback under global AuthenticationGuard — confirm @Public() or webhook 401s.
5. FilmOfCinema gap. No CRUD API; seat/showtime param misnamed (FOC.id vs Film.film_id).
6. Sync overlap. 4× EVERY_2_HOURS + chained fan-out, 10-min locks; 2 crons log-only.
7. Outbox GC. Deletes updatedAt<now-5m may drop unprocessed; FAILED never set.
8. Env/docker. Dockerfile EXPOSE 3000 vs PORT=4000; no .env.production; empty CSRF_SECRET fallback.
9. Docs drift. CLAUDE.md MoMo//momo, /metrics, /ticket Booking.
10. Order/Payment model. Redundant Order.paymentId? + Payment.orderId @unique; opaque AUTHENTICATION_NOT_NEEDED default.
